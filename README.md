# HeadsUp-Scouting.github.io

## Account-deletion pages

Proposed public URLs:

- French: https://www.headsupscouting.com/delete-account.html
- English: https://www.headsupscouting.com/delete-account_en.html

**Publication gate:** These pages are review drafts. Before merging to the publishing branch or otherwise deploying them, the product owner must approve the public copy in both languages and confirm:

- Which data categories are deleted, changed, or retained, including the effects on linked data and the retention periods and basis for anything retained.
- How identity is verified for emailed requests, including when someone no longer has access to their account email address.
- How requests are acknowledged, how completion is communicated, and how exceptions are handled.

The planned organization-based model is not implemented and is not a basis for current retention claims. The existing privacy-policy response window is not a deletion completion deadline. These drafts do not establish store-policy compliance.
